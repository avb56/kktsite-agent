Доступ к серверу

    С учётной записью касса подключается по адресу http://логин:пароль@…/api/v2/, а эта страница спросит логин и пароль. Пока учёток нет — сервер открыт всем в локальной сети.

    ККТ

    ККТ пока нет. Добавьте ККТ, с которой будет работать касса.

      Подключение кассы

      В кассе: Настройки ККТ → тип подключения «Атол Сервер», адрес каждой ККТ — на вкладке «ККТ» (?deviceID= выбирает ККТ). Адрес без deviceID — ККТ по умолчанию:

      С другого компьютера сети вместо — адрес этого компьютера. Если на сервере заведены учётные записи, логин и пароль пишутся в адресе: http://логин:пароль@…

      Версия и обновление

      Обновление скачивается с сайта, проверяется подписью, запускается пробно и только потом заменяет текущую версию. Перезапускается агент, когда очереди ККТ пусты (чек, который печатается, допечатается), — на несколько секунд касса не сможет печатать.

      Все выпуски и сборки для других систем — страница загрузок.

      HTTPS

      Нужен, только если браузер кассы не пускает её к серверу по http: касса открыта по https, и некоторые браузеры блокируют такие запросы. Chrome и Edge обычно только спрашивают разрешение на доступ к устройствам локальной сети — тогда HTTPS не нужен.

      Адрес для кассы — как выше, но с https:// и этим портом.

      Скачать сертификат
      Как доверить сертификату

      Браузер доверяет сертификату сервера, только если он установлен в систему кассового ПК. Сверьте отпечаток SHA-256 при установке с тем, что выше.

      • Windows: открыть скачанный kktsite-agent.crt → «Установить сертификат» → «Локальный компьютер» → «Поместить все сертификаты в следующее хранилище» → «Доверенные корневые центры сертификации». Перезапустить браузер.
      • macOS: открыть файл — он попадёт в «Связку ключей» → двойной щелчок по «kktsite-agent» → «Доверие» → «Всегда доверять».
      • Linux, Chrome: chrome://certificate-manager → «Локальные сертификаты» → «Установленные вами» → «Импорт» в «Доверенные сертификаты». Firefox: «Настройки» → «Сертификаты» → «Центры сертификации» → «Импортировать».
      • Проверить без установки: открыть адрес выше в браузере кассы и согласиться перейти на сайт — браузер запомнит исключение на время, но после перезапуска может спросить снова.

      Перевыпущенному сертификату доверяют заново: он другой. Перевыпускать нужно, когда у компьютера появился новый адрес или подходит срок — страница об этом скажет.

      Общие настройки

      43200 минут — 30 суток. Касса забирает результат сразу, дольше он нужен только для разбора.

      Чек, закрытый в ФН без бумаги, допечатается, когда её вставят, и только потом пойдут следующие. Без галочки следующие чеки пойдут сразу и завершатся ошибкой «Нет бумаги». Обрыв связи посреди чека останавливает очередь всегда — иначе чек можно пробить дважды.

      Перезапуск сервера

      Сервер запущен не службой — перезапустите его вручную.

      Нужен после обновления драйвера Атола: драйвер загружается при запуске сервера. Сервер дождётся, пока очереди ККТ опустеют, и перезапустится — на несколько секунд касса не сможет печатать.
